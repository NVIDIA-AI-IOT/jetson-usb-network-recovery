# Security policy

## Reporting a vulnerability

Report suspected security vulnerabilities in `jetson-usb-network-recovery`
privately to the NVIDIA Product Security Incident Response Team (PSIRT).
Do not disclose vulnerability details in public GitHub issues or pull requests.

Follow NVIDIA's [Report a Security Vulnerability](https://www.nvidia.com/en-us/security/report-vulnerability/)
instructions to use the vulnerability disclosure program or contact
[psirt@nvidia.com](mailto:psirt@nvidia.com). For email reports, use the PGP
encryption instructions linked from that page.

Include the repository URL, affected version or commit, steps to reproduce,
and potential impact. Do not include passwords, private keys, or other secrets.

For non-security bugs and usage questions, open a
[GitHub issue](https://github.com/NVIDIA-AI-IOT/jetson-usb-network-recovery/issues)
with sensitive information removed from any logs.
